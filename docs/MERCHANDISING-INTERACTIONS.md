# 货架布局与商品拖拽

进入超市端后，顶部“陈列工作台”用于直接调整布局和商品位置。新建设施仍使用下方“分类与门店位置”中的设施管理表单。

## 摆货架

- 在地图上点击货架，左侧打开该货架的陈列格位；下拉框也可以选择对应货架。
- 拖动货架时跟随指针，绿色虚线轮廓表示可落位，红色表示不可落位，地图下方显示原因。
- 地图始终用半透明绿底和虚线外边框标出可用于摆货架的整片地面，包含已经被货架占用的区域；不再标识左上角落点，也不按所选货架的大小裁切范围。主通道和固定收银/服务设施排除。实心柜体表示已占用，底色并不允许重叠安放；实际拖动、旋转和调整占地仍校验完整占地、重叠与通道。相连地面合并显示，区域层不阻挡点击和拖动；拖动框选占地时整体范围仍保持显示，并叠加当前矩形预览。
- 松手后吸附到网格，以约 270ms 的非线性缓动轻微回弹落稳。无效落点回到原位；支持系统“减少动态效果”偏好。
- 货架可跨分区移动、旋转或调整占地，所属分区仅用于归类，不限制坐标；不能与设施重叠、侵占主通道，也不能挡住其他货架原本可达的取货点。移动时所有侧面到达点同步平移，商品仍关联原货架。
- 地图可以缩放、滚动。键盘聚焦货架后，方向键每次移动一格，回车查看商品，Esc 取消拖动。
- 双面货架、冷藏柜、冷冻柜和服饰挂架可配置1–8层，冷冻柜新建时默认1层，已有多层配置不被强制改写。地图预检、移动/布局接口、商品层位选择和设施编辑共用层数规则，避免多层冷冻柜或服饰挂架显示可放却无法保存。服饰挂架新增默认1层，已有两层等配置在编辑时保留；生鲜岛台、堆头展示台、熟食服务柜台和活鲜池仍只支持1层。
- 工具条提供“顺时针90° / 逆时针90°”，以当前占地左上角为基准，每次转一个直角。占地宽高、到达侧和已陈列商品的侧面同步旋转，层数和格位号不变；服务柜台的员工操作带也随方向旋转。布局与商品位置一次事务保存，可撤销。
- 点击“框选占地”，用鼠标或触屏按住起点，沿对角拖到终点，松手确定矩形。拖动期间矩形、宽高格数和有效/无效颜色实时更新，支持任意对角方向；指针移出地图仍继续跟随并吸附边界，松手后范围不再随悬停移动。支持1–16格，确认“保存占地”后生效。保留层数、容量和商品，自动调整对应侧面的到达点；红色预览说明重叠、超界或挡路，不能保存。可直接再次拖动重画，或重选、取消和Esc；单击不会生成占地，拖动中断会恢复上次预览。
- 当前框选使用整块半透明色和虚线边框，显示在柜体上方：蓝色表示可保存，红色表示需调整；不再用两个角点代替范围。地图底层的绿色仍表示整体摆放地面，与当前框选区分开。

## 多选、组合和删除矩形货架

- 电脑端按住 Ctrl（Windows/Linux）或 Cmd（Mac）点击多个货架，再次点击可取消该货架的选择；点击空白地面清空选择。也可以开启工具条“多选”逐个选择，触屏同样适用。选中货架高亮，多选外侧显示蓝色虚线框。
- 松开修饰键，拖动任意已选货架，整组选中货架实时跟随，保持相对位置；方向键也会整体移动一格。所有落点一起检查，任意一件碰撞、越界或挡路，整组都不保存。
- 点击“组合”保存成员关系。之后点选或拖动任意成员都会选中、移动整个组合，刷新后仍保留。组合不合并实体占地、层数、格位或商品；可把多个组合与单架重新组合。
- 点击“分拆”解除所选组合，原货架、位置和商品全部保留。旋转或框选占地需要先分拆，再单独选择一个货架。
- 点击“删除”删除所有选中的货架；地图聚焦时也可以按 Delete 或 Backspace。关联商品移回“待摆放”，价格、库存和商品资料保留，其他货架地图编号不改变。删除状态与人工待摆放状态持久保存，重新启动不会自动补回货架或重新摆放这些商品。
- 组合、分拆、整体移动和删除均自动保存，可用“撤销上一步”恢复。删除撤销同时恢复原货架、组合和商品位置；若商品已被另行摆放、货架已改动或原空间被占用，会拒绝覆盖并提示刷新。撤销记录仅在当前页面会话保留。

## 摆商品

右侧选择目标货架并浏览推荐商品，可在“待摆放 / 已摆放 / 全部”之间切换，并搜索名称、品牌和 SKU；左侧集中显示地图、该货架的侧面和具体格位。

选择货架后，兼容且未摆放的商品优先，兼容且已经陈列的商品次之；不能放到该货架的商品保留在列表末尾，覆盖浅色蒙版并显示分组、冷链或资料未补全等原因，禁止从该列表误选拖入。切换货架会立即重新排序和校验，搜索和筛选继续有效。满层货架仍可替换已摆商品，具体操作由目标格位预检区分。

货架下拉框及侧面按钮显示已有商品数量；切换货架时优先打开有商品的一侧。未选商品时空层显示简洁提示，已有格位仍展示图片和名称。选中或拖动商品后，所有可见格位提前显示“可放入 / 可交换 / 可替换 / 不可放置 / 当前位置”，不可放置会直接显示冷链、分组或可达性原因并禁用点击，不必逐格悬停试探。空架明确标注整架为空。

缺少占地或侧面资料的旧位置仍可在下拉框中选择，关联商品单独列出并标注资料待补全，不虚构格位。到下方“分类与门店位置 → 货架设施”补全后才能编辑具体陈列。

| 操作 | 结果 |
| --- | --- |
| 已摆放商品拖到空格 | 移动，原格保留为空 |
| 已摆放商品 A 拖到商品 B 上 | 两件商品交换位置，包括跨货架交换 |
| 待摆放商品拖到空格 | 放入指定格位 |
| 待摆放商品拖到商品 B 上 | 替换 B，B 移回待摆放 |
| 拖到商品库区域 | 移回待摆放 |

拖动时显示商品浮层、目标格位和操作提示。需要跨货架时，可以从“已摆放”商品库拖入当前货架；也可以拖动中悬停地图上的另一货架，约 400ms 后切换目标面板，再拖进格位。

桌面端可直接拖动商品卡。手机端拖动卡片左侧手柄；也可先点击商品再点击目标格位，不要求精细拖动。点击商品左侧手柄可重新选择商品；点击已经选中的商品或按 Esc 取消选择。

每次操作自动保存，成功后可点击“撤销上一步”。交换和替换一次提交、一次事务保存，满层也可以交换。移动后的空格持久保存，刷新和顾客端货架视图保持一致。旧商品没有格位编号时按原始顺序填入空格，首次操作时只固定涉及层位的顺序，不做全库迁移。

容量、冷链条件、陈列分组和侧面可达性继续校验；交换时两件商品都必须适合新位置。并发位置变更会拒绝旧请求，不能覆盖别人刚改的位置；撤销也会检查当前状态。保存或刷新失败时页面提供错误及“刷新位置”入口，网络中断后请刷新核对实际保存状态。刷新页面后不保留本次会话的撤销记录。

## 2026-10-26 层数规则批量核对

服饰挂架在初始布局和当前门店中均为2层，但原公共规则只把双面货架、冷藏柜和冷冻柜视为多层设施，导致挂架移动、旋转、占地与组合移动被拒绝；旧设施编辑草稿还会强制降为1层。现在所有这些入口与商品层位检查统一承认服饰挂架可配置1–8层，新增时仍默认1层，不修改已有层数。

只读核对当前门店83条有效位置记录，其中70个矩形设施、13个未配置矩形的旧点位。修复前仅服饰挂架存在类型/层数冲突；修复后70个矩形设施的原位完整布局校验全部通过，服饰挂架四个方向的一格移动预检均通过。全部70个初始布局货架也已纳入回归检查。批量核对没有移动、降层或改写现有设施和商品；碰撞、地图边界、主通道、取货可达性及单层设施限制继续生效。

## 分类与门店位置

下方资料管理拆为“商品分类 / 门店分区 / 货架设施”三个页签，各自提供搜索、状态标记与整齐的编辑列表。新增表单默认折叠，展开后填写；分类、分区沿用自动保存，设施沿用明确的保存按钮。管理区错误直接显示在当前区域，不再混入商品录入表单。
