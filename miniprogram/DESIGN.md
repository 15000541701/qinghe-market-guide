# 青禾小程序界面约定

沿用项目根目录 DESIGN.md 的森林绿、暖白背景和固定分区色。小程序使用微信原生组件、系统中文字体与底部四项导航：导购、商品、地图、清单；超市端和连接设置通过导购页进入。

- 主文字 #263c30，主要操作 #315443，辅助文字 #606f56，背景 #f7f8f4，白色任务面板与 #e3e7de 边线。
- 使用 rpx 和原生导航栏；普通按钮保留至少 88rpx 高度。输入区以当前可用窗口高度布局，发送操作在原生底栏上方可见。
- 商品列表和后台字段使用两列弹性布局，保留余量避免 rpx 换算误差导致整列换行。照片来自现有服务端，不将商品图全部打包到小程序。
- 购物清单显式绑定非空状态，并核对实际渲染的商品行。金额、预计重量、已购状态和预算余量同时可见。
- 地图采用原生 Canvas 2D；分区目录提供文字操作入口。宽高同步缩放，位置为用户手动指定的虚拟位置。
- 价格建议保留来源、日期、计价单位和批发加价说明。新发地仅在点击查询时联网。
- 保留加载、失败、空结果和禁用状态。语音采用手机键盘提供的输入能力，未接独立录音识别插件。

实际模拟器截图位于项目的 .impeccable/review/mini/，属于本地验证产物，不提交代码包。
